## ⚡ Key Highlights

### 🎯 Immersive Cinematic Hero
* **Focused Center Typography**: Dynamic headings overlaying a high-contrast dark room camera setup editing monitor backdrop image.
* **Balanced Scrim Backdrop**: Utilizes feathered radial dark gradients to maximize text readability over high-definition details.
* **Instant Social CTAs**: Immediate navigation hooks to reels showreels and direct WhatsApp collaborations.

### 📊 Premium Pricing Calculator
* **Custom Dropdown Options**: Replaced native browser option select menus with styled option cards showcasing format details and itemized pricing specs.
* **Interactive Quantity Steppers**: Integrates custom numeric fields with animated `+` and `-` adjustments and typing validation limits.
* **Addon Toggle Modules**: Premium iOS-style neon switches for toggling express deliveries (24-48 hours) and sound design packages.
* **Dynamic Checkout Receipt**: Active calculations displaying sub-total price breakdowns with real-time numeric rolling counter animations.

### 👤 Profile Snapshot Card & Technical Grid
* **Portrait Snapshot Card**: Standardized full-bleed card (`aspect-ratio: 3/4`) in the About section with visual text overrides.
* **Refactored Technical Grid**: Desktop-optimized grid displaying editing software capabilities and specialties.

### 💳 Direct Payments Drawer
* **Quick Copy Node**: Interactive UPI details card with an instant text-copy action, tooltip status markers, and color-shifting feedback.
* **Vector Scanner Graphic**: Centered QR code framework with an Indian Rupee center badge.

## 🚀 How to Run Locally

Get the website running on your local machine in seconds:

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Gautamgiri798/Bikash-Suna-Portfolio.git
   ```

2. **Navigate into the Workspace**
   ```bash
   cd Bikash-Suna-Portfolio
   ```

3. **Start a Local Web Server**
   * Using Python (Recommended):
     ```bash
     python -m http.server 8000
     ```
   * Or using Node.js:
     ```bash
     npx http-server -p 8000
     ```

4. **Launch in Browser**
   Open your browser and navigate to:
   👉 **[http://localhost:8000](http://localhost:8000)**
